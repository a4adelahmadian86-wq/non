# FARAST — پلتفرم خدمات و محصولات دیجیتال

مخزن اصلی سایت FARAST بر پایهٔ Laravel 12 و PHP 8.2 است. این مخزن هستهٔ سایت، فروشگاه محصولات دیجیتال، خدمات آنلاین، ویرایشگر، پردازش اسناد محصول، دستیار هوشمند، حساب کاربری و پنل مدیریت را نگهداری می‌کند.

## معماری فعلی در کد

- **هسته:** Laravel 12؛ MySQL یا PostgreSQL طبق محیط نصب.
- **داده و دانش:** دیتابیس اصلی Laravel منبع حقیقت محصولات، کاربران، مجوزها، صف، متن استخراج‌شده، chunkها، factها و حافظهٔ خصوصی کاربران است.
- **صف:** صف دیتابیس‌محور Laravel؛ jobهای ناموفق و وابسته به سرویس خارجی باید در صف باقی بمانند و retry شوند.
- **فایل‌ها:** همهٔ ماژول‌ها از `StorageManager` استفاده می‌کنند؛ فایل‌های حساس محصول به `iran_primary` و فایل‌های غیرحساس به `foreign_primary` مسیریابی می‌شوند.
- **بکاپ:** `StorageBackupService` نسخهٔ پشتیبان رمزگذاری‌شدهٔ AES-256 می‌سازد، پس از انتقال checksum را بررسی می‌کند و از مقصد اختیاری `iran_backup` پشتیبانی می‌کند.
- **پردازش محصول:** `ProductSupervisorClient` به سرویس مستقل Product Supervisor متصل می‌شود و endpoint جایگزین دارد.
- **AI و گفتار:** درگاه AI، سرویس گفتار و Product Supervisor سرویس‌های جداگانه‌اند؛ نباید نقش یا endpointهایشان با هم اشتباه گرفته شود.
- **حریم خصوصی:** حافظهٔ خصوصی کاربر از دانش عمومی محصول جداست. استنباط‌های رفتاری و پروفایل داخلی نباید به کاربر نمایش داده شوند.

## وضعیت استقرار

وجود فایل Docker، Blueprint یا اسکریپت deploy در Git به‌تنهایی به معنی ساخته‌شدن سرویس یا آماده‌بودن Production نیست. هر endpoint باید با health/readiness واقعی و درخواست احراز هویت‌شده آزمایش شود؛ تا آن زمان وضعیت آن «تأییدنشده» است.

## اصول امنیتی و توسعه

- کلیدها و رمزها فقط در environment/secret manager نگهداری می‌شوند؛ هیچ secret واقعی در Git قرار نمی‌گیرد.
- فایل‌های خصوصی فقط از مسیرهای کنترل‌شده و URLهای امضاشدهٔ کوتاه‌مدت ارائه می‌شوند.
- قیمت، دسترسی، پرداخت و مجوزها فقط از منطق سمت سرور تعیین می‌شوند.
- تحلیل AI مجوز انتشار یا تأیید انسانی را دور نمی‌زند.
- تغییرات زیرساختی در شاخهٔ مستقل و Pull Request انجام می‌شوند؛ قبل از merge، تست‌ها و بررسی سازگاری با ساختار موجود الزامی است.
