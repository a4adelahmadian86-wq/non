## قرارداد استفاده از این ماتریس

1. برای route دقیق و line source به `ROUTE_OWNERSHIP_INVENTORY.md` مراجعه شود.
2. برای model/relation به `MODEL_OWNERSHIP_INVENTORY.md` و برای schema/FK/index به `MIGRATION_SCHEMA_INVENTORY.md` مراجعه شود.
3. برای service/controller call-site به `SERVICE_DEPENDENCY_INVENTORY.md` و `CONTROLLER_CALLSITE_INVENTORY.md` مراجعه شود.
4. پیش از تغییر هر قابلیت، همه ردیف‌های این ماتریس و تمام مصرف‌کنندگان در inventoryهای مکمل بررسی شوند.
5. هیچ ردیف «شکاف ردیابی» را با نام یک تست کلی بسته‌شده تلقی نکنید؛ بستن شکاف مستلزم assertion منفی/مثبت روی همان route/action، actor role، owner/scope و side effect است.

## وضعیت پوشش

این ماتریس ۱۳ حوزه دامنه‌ای را به منبع داده، سرویس، کنترلر/Route، gate و آزمون‌های موجود متصل می‌کند. این یک نقشه traceability اولیه است، نه ادعای پوشش ۱۰۰٪ تمام ۳۳۴ Route. برای پذیرش نهایی، تست‌های هر mutation حساس باید به‌صورت route/action-level و با نقش مجاز/غیرمجاز و مالک/غیرمالک بازبینی شوند.
