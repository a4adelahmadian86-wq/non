# معیارهای استاندارد سیستم پشتیبانی / Help Desk

مرجع: رویه‌های رایج help desk (SLA FRT/TTR، CSAT، صف ادمین، کانال واحد).

## الزامات پایه (Must-have)

1. **چرخه حیات تیکت** — open → pending → answered / user_replied → closed با ردپای قابل ممیزی
2. **اولویت و دپارتمان** — high / normal / low + صف‌های پشتیبانی، فروش، مالی، شکایات
3. **ارجاع خودکار / دستی** — least-loaded یا انتخاب کارشناس
4. **SLA**
   - First Response Time (FRT) به ازای اولویت
   - Time to Resolution (TTR)
   - تقویم ساعات کاری (ایران: ۹–۱۸، آخر هفته قابل تنظیم)
   - **توقف ساعت حل** وقتی وضعیت «در انتظار کاربر» (pending) است
   - هشدار قبل از نقض + اعلان نقض
5. **چندکاناله به یک صف** — ویجت مهمان + داشبورد کاربر + میز ادمین
6. **اعلان** — درون‌برنامه + ایمیل + پیامک (قابل خاموش/روشن per event)
7. **CSAT** پس از بستن (۱–۵)
8. **گزارش** — میانگین FRT، نرخ رعایت SLA، توزیع CSAT، عملکرد کارشناس
9. **یادداشت داخلی** — فقط برای staff
10. **پیوست فایل** با محدودیت نوع/حجم

## اعلان‌های سازمانی (Announcements)

- **فقط داخل حساب کاربری / داشبورد** (نه صفحهٔ عمومی فروشگاه)
- انتشار به مخاطب: همه / کاربران / مدیران
- کانال: اعلان درون‌برنامه و در صورت نیاز ایمیل

## KPI پیشنهادی

| شاخص | هدف نمونه |
|------|-----------|
| FRT اولویت بالا | ≤ ۶۰ دقیقه کاری |
| FRT عادی | ≤ ۴ ساعت کاری |
| TTR عادی | ≤ ۱ روز کاری |
| نرخ رعایت SLA پاسخ | ≥ ۸۰٪ |
| CSAT میانگین | ≥ ۴ از ۵ |
