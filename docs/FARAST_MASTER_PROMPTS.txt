CORE UX PRINCIPLES
------------------
1. The product must feel like a serious SaaS application, not a collection of static pages.
2. Every visible important feature must connect to a real backend workflow whenever the feature is presented as functional.
3. Never create fake buttons, fake statistics, fake payment success, fake downloads, fake AI results, fake admin actions, or fake data merely to make a screen look complete.
4. If an external provider is not configured, show an accurate configuration state and provide a safe fallback where appropriate; never claim a live integration that does not exist.
5. Preserve user work across navigation, reloads, recoverable failures, and appropriate session states.
6. Provide clear loading, success, warning, error, empty, disabled, offline, permission, and processing states.
7. Prefer progressive enhancement and graceful degradation.
8. Keep the UI responsive from desktop to tablet to mobile.
9. FARAST supports Persian RTL as a first-class interface, while technical content may remain LTR where appropriate.
10. Use professional iconography. Icons should communicate actions without relying on text-only buttons when an icon is standard and recognizable.
11. Tooltips must be Persian and should include keyboard shortcuts when a shortcut exists.
12. Do not introduce unnecessary horizontal scrolling in core application interfaces.
