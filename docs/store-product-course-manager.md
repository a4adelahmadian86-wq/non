# مرکز مدیریت محصولات و دوره‌های آموزشی فراست

## معماری

این ماژول دو نوع محصول را در کاتالوگ مشترک نگهداری می‌کند:

- `digital_file`: محصول دانلودی با یک فایل اصلی و فایل‌های پیش‌نمایش
- `course`: محصول آموزشی با یک رکورد دوره، فصل‌ها، جلسات و منابع اختصاصی هر جلسه

اطلاعات تجاری (عنوان، شناسه، قیمت، دسته، وضعیت، کاور و SEO) در `store_products` باقی می‌ماند. داده‌های آموزشی در جدول‌های `store_courses`، `store_course_sections` و `store_course_lessons` نگهداری می‌شوند.

دسترسی خریدار به دوره از طریق `store_library_items` صادر می‌شود و ثبت‌نام آموزشی متناظر در `store_course_enrollments` ساخته می‌شود. پیشرفت هر جلسه در `store_course_lesson_progress` ثبت می‌شود. ایجاد دسترسی برای پرداخت رایگان، کیف پول و callback تأییدشده زرین‌پال یکپارچه است.

## راه‌اندازی عملیاتی

1. مهاجرت‌ها را اجرا کنید:

   ```bash
   php artisan migrate --force
   ```

2. دیسک `private` باید واقعاً خصوصی باشد؛ آن را به مسیر عمومی وب‌سرور یا symlink پوشه `public` متصل نکنید. مجوز نوشتن فقط به کاربر سرویس PHP داده شود.

3. ClamAV را روی سرور نصب کنید و مسیر باینری را در محیط برنامه تنظیم کنید:

   ```dotenv
   FARAST_CLAMSCAN_BINARY=/usr/bin/clamscan
   ```

   مسیر بالا نمونه متداول لینوکس است؛ مسیر واقعی نصب را وارد کنید. کاربر PHP باید اجازه اجرای باینری و خواندن فایل قرنطینه‌شده را داشته باشد. اگر اسکنر تنظیم نشده باشد یا اسکن با خطا مواجه شود، بارگذاری فایل جدید عمداً fail-closed است و فایل ثبت/قابل انتشار نمی‌شود.

4. برای نمایش کاورهای عمومی، دیسک `public` و symlink استاندارد لاراول را فعال کنید:

   ```bash
   php artisan storage:link
   ```

   کاورها فقط پس از اسکن موفق از قرنطینه خصوصی به دیسک عمومی منتقل می‌شوند. فایل‌های دانلود و منابع آموزشی هرگز در دیسک عمومی ذخیره نمی‌شوند.

5. محدودیت‌های ورودی وب‌سرور و PHP را با سقف بارگذاری ۲۵۶ مگابایت منابع جلسه هماهنگ کنید؛ برای نمونه `upload_max_filesize=256M` و `post_max_size=260M`. سقف فایل اصلی محصول ۵۰ مگابایت و کاور ۸ مگابایت است.

6. مسیرهای جدید را بررسی کنید:

   ```bash
   php artisan route:list --path=admin/store
   php artisan route:list --path=my-courses
   ```

## گردش کار مدیر

1. از کنسول مدیریت وارد «محصولات و دوره‌ها» شوید.
2. محصول جدید را ایجاد و نوع آن را انتخاب کنید.
3. برای فایل دانلودی، فایل اصلی را بارگذاری کنید؛ برای دوره، ابتدا تنظیمات دوره و سپس فصل‌ها و جلسات را بسازید.
4. منابع هر جلسه را جداگانه بارگذاری کنید.
5. یک جلسه منتشرشده برای دوره یا یک فایل اصلی اسکن‌شده برای محصول دانلودی لازم است.
6. صفحه فروش را پیش‌نمایش کنید و سپس محصول را منتشر کنید.

محصول تازه همیشه ابتدا پیش‌نویس می‌شود. محصول دارای سفارش یا دسترسی مشتری به‌جای حذف فیزیکی، بایگانی می‌شود تا سابقه خرید و حق دسترسی خریداران از بین نرود.

## دسترسی دانشجو و امنیت تحویل

- دانشجو فقط از طریق کتابخانه و با دسترسی فعال وارد دوره می‌شود.
- تاریخ انقضای دسترسی در زمان خرید محاسبه و ذخیره می‌شود.
- انتشار تدریجی جلسه‌ها در سمت سرور کنترل می‌شود؛ پنهان‌کردن صرفاً در رابط کاربری کافی نیست.
- منابع جلسه فقط در صورت تعلق به همان محصول و جلسه، فعال‌بودن و وضعیت اسکن سالم تحویل می‌شوند.
- checksum فایل هنگام تحویل دوباره کنترل می‌شود تا تغییر محتوا پس از اسکن یا ثبت، شناسایی شود.
- فایل‌های قدیمی با وضعیت `legacy` برای قطع‌نشدن دسترسی خریداران قبلی حفظ می‌شوند. فایل‌های تازه فقط پس از اسکن موفق `clean` می‌شوند.

## محدوده فعلی

- جلسات نمونه رایگان، پیش‌نمایش عمومی متن/پیوند ویدئو، انواع جلسه و ثبت پیشرفت پیاده‌سازی شده‌اند.
- پیوندهای ویدئویی خارجی در تب جدید باز می‌شوند؛ این نسخه هنوز اتصال اختصاصی به سرویس‌های میزبانی/پردازش ویدئو یا DRM ندارد.
- گزینه فعال‌سازی گواهی در تنظیمات دوره ذخیره می‌شود، اما تولید PDF گواهی و سامانه کد اعتبارسنجی گواهی در این مرحله پیاده‌سازی نشده است.
- آزمون‌ها، تکالیف، پرسش‌وپاسخ و انجمن دوره در دامنه نسخه فعلی نیستند.

## پشتیبان‌گیری

پشتیبان‌گیری باید هم‌زمان شامل دیتابیس و دیسک خصوصی فایل‌ها باشد. بازیابی دیتابیس بدون فایل‌های خصوصی می‌تواند دسترسی‌های ثبت‌شده را به فایل‌های غیرقابل دریافت تبدیل کند.
